# ЛР4 — Цикли, функції, функціональні вирази. Console

Скрипт `js/monitoring.js` підключено в `<head>` з `defer`. DOM не змінює — результат у DevTools → Console.

## Відповідність завданню
| Пункт | Реалізація |
|---|---|
| `for...of` + `continue` | `calculateAverage`, `findMinimum/Maximum`, `countByCategory` |
| `for` + `break` | `findFirstCritical` (потрібна позиція) |
| `while` | `findRecovery` — 3 безпечні поспіль після першого критичного, скидання лічильника |
| `do...while` | `findFirstValid` — порожній масив відсікається окремо |
| Без `filter/reduce/Math.min/max` | дотримано |
| Function Declaration + hoisting | `findFirstCritical` викликається в розділі 3, оголошена в розділі 5 |
| Function Expression | `const countByCategory = function…`, передається як callback в `analyzeWith(data, limits, countByCategory)` |
| Arrow (1 і кілька параметрів) | `statusLabel = value => …`, `isAbove = (value, threshold) => …` |
| Обчислення ≠ виведення | `buildReport` тільки рахує, `printReport` тільки друкує |
| Тестові набори | `runTests`: `[]`, `[-1, 141]`, `[70, 85, 86]`, дві перервані серії → `console.table` |

## Результат (збігається з прикладом у методичці)
26 коректних / 2 некоректних; 13 / 9 / 4; середнє 68,38 dB; min 39, max 95;
перше критичне 91 dB, позиція 9; відновлення не знайдено.

## Для захисту
- **Чому Declaration можна викликати раніше:** на етапі створення контексту функція-оголошення реєструється повністю (ім'я + тіло).
  `const` теж «піднімається», але без значення — до рядка ініціалізації це TDZ → `ReferenceError`.
- Ранній виклик стоїть *після* стрілкових функцій: `findFirstCritical` всередині викликає `isAbove` (const), тож вище був би `ReferenceError`.
- **Прогноз для порога 85:** перше значення > 85 — `91` (індекс 8 → позиція 9). `85` — це ще попередження (умова `level > critical`).
- **do...while:** для непорожнього масиву перший елемент треба перевірити в будь-якому разі, а умова продовження має сенс лише після перевірки.

## Як перевірено (автотест у Chromium, 39/39 ✓)
- Звіт у Console рядок у рядок збігається з прикладом методички (див. вище).
- Функції викликались напряму з тестовими даними: `[]` → усі `null`; `[-1, 141]` → `null`; `70/85/86` → по одному в кожному класі; перервані серії → позиції 7 і 6; без критичних → відновлення `null`.
- Основний масив після роботи не змінений (28 елементів).
- У робочому коді немає `filter/reduce/Math.min/Math.max`.

## Що показати на захисті
- п. 6.1.2: на початку файлу закоментовано блок `console.log / warn / error` — розкоментувати, показати фільтри Console і посилання `monitoring.js:рядок`, потім закоментувати назад.
- Hoisting: у Console викликати `countByCategory` до ініціалізації не вийде (у робочому файлі цього виклику немає — пояснення в коментарі розділу 3).
- Перевірка виразів у Console — готові приклади в кінці файлу.
